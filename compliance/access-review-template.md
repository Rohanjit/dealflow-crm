# Quarterly access review

Copy this file for each review (for example `access-review-2027-Q1.md`) and keep the copies with the
firm's records. Takes about 30 minutes. Everything below is on Settings → Users, Roles & permissions
and Security.

**Dealflow version (Settings footer / image digest):** ______

## 1. People

| Person | Role | Still at the firm and needs access? | Role still right? | Two-step login set up (both ways)? | Action |
|---|---|---|---|---|---|
| | | Yes / No | Yes / No | Passkey / App / Both | |

- [ ] Leavers deactivated (Settings → Users), their sessions ended.
- [ ] Nobody is an admin who doesn't need to be; at least two admins remain.
- [ ] Nobody without two-step login (the security checklist shows the names).

## 2. Roles and field access

- [ ] Each role's module permissions match the job (view / create / edit / delete).
- [ ] Hidden and read-only fields still right (fees, valuations, personal details).
- [ ] "Send campaigns", "See team performance", "Restore from archive", "Manage users", "Manage
      settings" given only where needed.

## 3. Restricted deals

- [ ] Each restricted deal's team and named people are still right (deal page → Access).
- [ ] Old access requests decided.

## 4. Vault

- [ ] People holding the Vault key are the ones who should (Settings → Security → Encryption and keys).
- [ ] A Vault recovery key exists and its offline copy was checked this quarter.

## 5. Security checklist

- [ ] Settings → Security: every item green, or each exception written down below with a date to fix.
- [ ] "Test the latest backup now" passed; backup key file and audit passphrase stored offline.
- [ ] Notification bell: security alerts of the quarter reviewed (lock-outs, refused files, new devices).

## 6. Audit log sample

- [ ] Fetch one week (Settings → Audit log). Spot-check exports, permanent deletions, role changes and
      sign-ins from unusual addresses. Note anything unexplained.
